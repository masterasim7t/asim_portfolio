# Alex Rivera — Dummy Portfolio

A placeholder single-page portfolio built with plain HTML, CSS and JavaScript. All names, companies, dates, emails and projects are fictional sample content; replace them with your own.

The animated avatar/mascot and the resume PDF from the original have been removed.

## Run locally

Open `index.html` in a browser, or run `python -m http.server 8000` and visit http://localhost:8000.

## Files

- `index.html` — content and structure
- `styles.css` — layout, themes, animations
- `script.js` — menu, theme toggle, scroll effects, project dialogs
- `Pages/pages/` — sub-pages for About and each project
